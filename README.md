# Smalldis

A small redis for small projects, the goal of this is to be able to setup and run a redis within minutes on any local machine with minimal overhead,
while still providing features necessary for a redis package.




## Usage Instructions

Simply clone the repository:

```terminal
git clone https://github.com/LOLFUTUREVEVO/smalldis.git
```

Build The Project:
```terminal
make
```

And run the binary:
```terminal
./smalldis
```
